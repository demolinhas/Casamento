Meu Vídeo com Auto-Play

Nota: Por políticas dos navegadores, o auto-play só funciona com o vídeo mudo (muted). Os usuários podem ativar o som usando os controles do vídeo.

Como Fazer Seu Próprio Site de Vídeo

  1. Faça uma conta no GitHub
  2. Crie um novo repositório com o nome "seuusuario.github.io" (substitua "seuusuario" pelo seu nome de usuário)
  3. Faça upload deste arquivo HTML (salve este código em um arquivo chamado "index.html")
  4. Substitua a URL do vídeo no código pelo link do seu próprio vídeo
  5. Seu site estará disponível em https://seuusuario.github.io

Alternativas gratuitas: Você também pode usar Cloudflare Pages, Netlify ou Vercel.
